# ちばらきAIコミュニティ Discordサーバー設定計画書

Stripe決済で会費を支払った人だけが、Discordのロール権限でメンバー限定コンテンツを閲覧できる建付けにするための設定・運用計画です。

---

## 1. ロール設計

| ロール名 | 色 | 対象 | 主な権限 |
|---|---|---|---|
| 👑 運営 | 金 | 主宰者（SOUTH） | 管理者権限すべて |
| 🛠️ モデレーター | 青緑 | 信頼できる協力メンバー | メッセージ管理・メンバータイムアウト・イベント作成 |
| 🤖 Bot | グレー | 各種Bot | 必要最小限（ロール管理を任せるBotのみロール管理権限） |
| 💎 プレミアム会員 | 紫 | 将来の本部アクセス権プラン（+5,000円〜） | レギュラー会員の全権限＋プレミアム限定カテゴリ閲覧 |
| ✅ レギュラー会員 | ブランドグリーン | 月額3,000円の決済確認済みメンバー | 会員限定カテゴリの閲覧・書き込み |
| 🔰 ビジター | ライトブルー | 無料イベント参加者・入会検討中 | 公開カテゴリのみ閲覧・書き込み |
| （@everyone） | — | 参加直後・未認証 | #はじめに と #お知らせ の閲覧のみ（書き込み不可） |

**設計のポイント**

- 「決済した人だけが見られる」を実現する仕組みは、**会員限定カテゴリの権限を @everyone 非表示にし、✅レギュラー会員ロールにのみ閲覧を許可する**こと。ロール付与＝閲覧解禁、ロール剥奪＝即閲覧不可、というシンプルな構造にする。
- ロールの上下関係（表示順）は 運営 > モデレーター > Bot > プレミアム > レギュラー > ビジター の順に置く。Botにロール付与を任せる場合、**Botのロールは付与対象ロールより上に置く**必要がある。
- ビジターロールを設けるのが重要。無料イベント参加者をDiscordに入れて「コミュニティの賑わいを見せつつ、会員限定部分は見えない」状態を作ると、入会動機（FOMO）につながる。

## 2. チャンネル設計

### 📖 公開カテゴリ（@everyone / ビジター閲覧可）

| チャンネル | 用途 | 権限 |
|---|---|---|
| #はじめに | サーバーの歩き方・入会方法・ロール申請手順 | 全員閲覧可・書き込み不可 |
| #お知らせ | イベント告知・運営からの連絡 | 全員閲覧可・書き込み不可（運営のみ投稿） |
| #自己紹介 | 参加者の自己紹介 | ビジター以上書き込み可 |
| #雑談ラウンジ | 誰でも参加できる雑談 | ビジター以上書き込み可 |
| #入会案内 | 料金・Stripe決済リンク・入会手順の案内（固定メッセージ） | 全員閲覧可・書き込み不可 |

### 🔒 会員限定カテゴリ（✅レギュラー会員以上のみ）

@everyone・ビジターには**カテゴリごと非表示**に設定。

| チャンネル | 用途 |
|---|---|
| #会員-お知らせ | 会員向けイベントの先行案内・優先申込 |
| #イベント申込 | 勉強会・ワークショップの申込スレッド |
| #質問-ai活用 | AIツールの質問し放題チャンネル |
| #情報共有 | 最新AIニュース・使ってみた報告 |
| #アーカイブ資料 | 勉強会スライド・録画リンク集（書き込みは運営のみ） |
| #共同制作プロジェクト | ワークショップの進行・成果物共有 |
| #エリア別-千葉（松戸・柏・我孫子） | 地元ネタ・現地集合の調整 |
| #エリア別-茨城（取手・土浦） | 同上 |
| 🔊 もくもく作業VC | ボイスチャンネル（作業会・オンライン相談） |

### 🛠️ 運営カテゴリ（運営・モデレーターのみ）

| チャンネル | 用途 |
|---|---|
| #運営-連絡 | 運営メンバー間の連絡 |
| #決済-照合ログ | 入会申請とStripe決済の照合記録（後述の運用フロー用） |

## 3. Stripe決済とロール付与の連携方法

### フェーズ1（〜50名目安）：手動運用【まずはこれで開始】

コストゼロ・障害ポイントなしで即日始められる。50名程度までは十分回る。

1. Stripe **Payment Link**（サブスクリプション・月額3,000円）を作成し、Webサイトの入会ボタンに設定する
2. Payment Linkの決済完了後リダイレクト先を `thanks.html` に設定する
3. `thanks.html` に **Discord招待リンク**（無期限・回数無制限で発行）を掲載する
4. 新規参加者は #はじめに の案内に従い、**決済時のメールアドレス**をGoogleフォームまたは運営DMで申請する
5. 運営がStripeダッシュボードで決済を確認し、✅レギュラー会員ロールを手動付与する（目標：24時間以内）
6. **解約検知**：Stripeの通知メール（サブスクリプションのキャンセル通知をONにする）を受けたら、該当メンバーのロールを剥奪する。月1回、Stripeのアクティブな契約者一覧とロール保持者一覧を突き合わせて漏れを確認する

補助ツール：Stripe設定 → 「ビジネス設定 > 通知」でキャンセル・支払い失敗のメール通知を有効化しておくこと。

### フェーズ2（50〜150名目安）：連携サービスで自動化

手動照合が負担になってきたら、以下のいずれかを導入する。

| 方法 | 概要 | 費用感 | 備考 |
|---|---|---|---|
| **LaunchPass** | Stripe連携でDiscordの有料メンバーシップを丸ごと管理。決済→自動参加→自動ロール付与→解約時自動剥奪 | 月額$29〜＋決済手数料 | 導入が最も簡単。日本円プラン対応可 |
| **Zapier / Make** | Stripe「サブスク作成/キャンセル」トリガー → Discordロール付与/剥奪 | 無料枠〜月数千円 | Discord側の連携に工夫が必要（Bot併用） |
| **自作Bot（Stripe Webhook）** | `customer.subscription.created / deleted` のWebhookを受けてdiscord.jsでロール操作 | サーバー代のみ | 自由度最高。技術的メンテナンスが必要 |
| **Discord公式サーバーサブスク** | Discord内課金でロール自動管理 | 手数料10% | 日本からの利用可否・iOSアプリ内課金の手数料増に注意。Stripeで統一する方針なら不採用 |

**推奨**：フェーズ2では LaunchPass（早く確実）か、AIコミュニティの題材を兼ねて**自作Bot をメンバーと共同制作**するのも面白い（コンテンツ化できる）。

### フェーズ3（150名〜）：本部プラン追加

- Stripeに「プレミアムプラン」（+5,000〜10,000円）の商品を追加し、💎プレミアム会員ロールと連動
- 六本木本部サーバー（または本部カテゴリ）へのアクセス権を紐付け

## 4. サーバー初期設定チェックリスト

- [ ] サーバー名を「ちばらきAIコミュニティ」に設定、アイコンにロゴ画像を設定
- [ ] 認証レベルを「中」（登録5分以上のアカウントのみ発言可）に設定
- [ ] 明示的コンテンツフィルターを「全メンバーに適用」に設定
- [ ] 上記ロールを作成し、表示順を整える（Bot > 付与対象ロール）
- [ ] 会員限定カテゴリを作成し、@everyone の「チャンネルを見る」をOFF、✅レギュラー会員をONに設定
- [ ] コミュニティ機能（サーバー設定 > コミュニティを有効化）をON → オンボーディング・ルールスクリーニングを設定
- [ ] ルールスクリーニング（同意必須のルール）を設定：誹謗中傷禁止、無断営業・勧誘禁止、決済情報の共有禁止 など
- [ ] #はじめに に「サーバーの歩き方」「会員ロール申請手順」を固定メッセージで投稿
- [ ] #入会案内 に料金表とStripe決済リンクを固定メッセージで投稿
- [ ] 招待リンクを発行（thanks.html用：無期限・回数無制限／無料イベント告知用：7日期限の別リンクにすると流入元を区別できる）
- [ ] 監査ログの確認方法を把握（ロール付与・剥奪の記録が残る）
- [ ] AutoMod（キーワードフィルター・スパムブロック）を有効化

## 5. 運用ルール

- **ロール付与SLA**：申請から24時間以内に付与。付与したら #決済-照合ログ に「日付・Discord名・決済メール」を記録
- **解約時**:ロール剥奪のみ行い、サーバーからはキックしない（ビジターに戻す）。復帰のハードルを下げ、再入会導線を残す
- **支払い失敗時**:Stripeの自動リトライ（スマート再試行）を有効化。最終的に失敗した場合のみロール剥奪
- **月次棚卸し**:毎月1日にStripeのアクティブ契約者数とレギュラー会員ロール数を照合

## 6. 導入スケジュール（目安）

| 週 | やること |
|---|---|
| 第1週 | ロール・チャンネル作成、権限設定、固定メッセージ整備 |
| 第2週 | Stripe Payment Link作成、thanks.htmlに招待リンク設置、テスト決済でフロー通し確認 |
| 第3週 | 無料イベント参加者をビジターとして招待開始 |
| 第4週〜 | 入会受付開始、手動ロール付与運用。50名到達を目安にフェーズ2の自動化を検討 |
