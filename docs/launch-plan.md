# ちばらきAIコミュニティ 立ち上げ計画書（価格設計・初期集客・導線設計）

対象エリア：松戸・柏・我孫子・取手・土浦・北千住（常磐線沿線）
目標：初期リスト100名 → 有料会員化

---

## 1. 価格設計の考え方

### 月額3,000円は妥当か

- 地域の習い事相場（大人の英会話・音楽教室：月5,000〜10,000円）と比べれば、月2〜3回のリアルイベント参加込みで3,000円は**割安に見せられる価格**。妥当なライン。
- ただしローカルでは「コミュニティにお金を払う」習慣自体がないため、**金額よりも「何が毎月手に入るか」の言語化が勝負**。「月2回の勉強会＋質問し放題＋アーカイブ」のように回数と具体物で示す。
- 損益の目安：会費3,000円 × 30名 = 月9万円。レンタルスペース代（1回1〜2万円 × 月2〜3回）と諸経費を引いても回り始めるのは**有料会員25〜30名**あたり。まずここを最初のマイルストーンにする。

### 推奨する価格戦術

| 施策 | 内容 | 狙い |
|---|---|---|
| 創設メンバー価格 | 先着30名は月2,000円（永年） | 初速をつくる・「先に入るほど得」の空気 |
| 初月無料 or 500円 | Stripeのトライアル機能で設定可能 | 決済のハードルを下げる |
| イベント都度課金との併設 | 非会員はイベント1回2,000円、会員は無料 | 「2回来るなら会員が得」という比較対象を作る |
| 年払いプラン | 30,000円/年（2ヶ月分お得） | 解約率低下・キャッシュ先行 |

### 将来のプレミアムプラン（六本木本部アクセス +5,000〜10,000円）

- ローカル→都心という「昇格」の物語は強い。ただし本部が実在してから告知する。当面はサイト上で「準備中」表示に留め、期待感の演出に使う（実装済み）。

## 2. 初期集客：100名リスト獲得プラン

### 基本戦略

「Threads（発見）→ LINE公式（リスト化）→ 無料イベント（体験）→ Stripe決済（入会）」の一本道に絞る。初期はWebサイトを「信頼の担保・受け皿」として使い、能動的な集客はThreadsに集中する。

### Threads運用（メインチャネル）

- **地名を必ず入れる**：「柏でAI勉強会やります」「松戸のカフェでChatGPT触ってきた」など、投稿の1行目に地名。ローカル地名はThreadsのレコメンドで同エリアのユーザーに届きやすい。
- **投稿の型（週5〜7投稿）**
  1. 地元×AI体験談（「取手の実家の親にChatGPT教えたら…」）
  2. AI初心者向けTips（スクショ付きで再現できるもの）
  3. イベント告知・開催レポート（会場写真・参加者の声）
  4. 問いかけ型（「常磐線沿線でAI勉強してる人いますか？」）
- **プロフィールリンクはLINE登録URL一本**に絞る（選択肢を増やさない）。
- 開催レポートが最強の広告。第1回無料イベントは写真撮影の許可を取り、翌日レポート投稿→次回募集の流れを作る。

### 無料イベント設計

- タイトル例：「【参加無料】はじめてのAI活用セミナー in 柏 〜スマホだけでOK〜」
- 定員20〜30名 × 月2回 × 2〜3ヶ所（柏・松戸・北千住をローテーション）→ 2ヶ月で100名リストが現実的。
- 内容は「その場で手を動かして、帰り道に人に話したくなる」もの（例：自分の仕事をAIに手伝わせるハンズオン、AIで地元の観光ポスターを作る）。
- イベント終盤5分で入会案内：創設メンバー価格・その場入会特典（当日入会で初月無料など）を提示。**その場でStripe決済のQRコードを配る**のが最も成約率が高い。

### KPI目安

| 指標 | 目標 |
|---|---|
| Threadsフォロワー | 3ヶ月で1,000名 |
| LINE登録（リスト） | 3ヶ月で100名 |
| 無料イベント参加率 | LINE登録者の30〜40% |
| 有料転換率 | イベント参加者の20〜30% |
| 有料会員 | 3ヶ月で25〜30名（損益分岐）、6ヶ月で50名 |

## 3. 導線設計：LINE公式 vs Webサイト

**結論：両方使う。ただし役割を分ける。**

- **LINE公式アカウント＝リストの本体**。Threadsからの誘導先はLINE一本。イベント告知・リマインド（前日・当日朝）・入会案内をすべてLINEで行う。無料プラン（月200通）で開始し、超えたらライトプランへ。
- **Webサイト＝信頼の担保と決済の受け皿**（本リポジトリ）。Threadsのプロフィールや検索から来た人が「ちゃんとしたコミュニティだ」と確認する場所。料金・入会フロー・特商法表記を置き、Stripe決済への入口を担う。
- リスト取得フォームをサイトに置くより、LINE登録に寄せる方がローカル層には摩擦が少ない（メールよりLINEが日常）。

### 導線の全体図

```
Threads投稿（地名×AI）
   └→ プロフィールのLINE登録URL
        └→ LINE：あいさつメッセージ＋無料イベント案内
             └→ 無料イベント参加（オフライン体験）
                  └→ その場でQR → Webサイト料金ページ → Stripe決済
                       └→ thanks.html → Discord参加 → 会員ロール付与
```

### LINE公式の初期設定

- あいさつメッセージ：自己紹介＋次回無料イベントの日程＋Webサイトリンク
- リッチメニュー（3枠）：「無料イベント情報」「入会案内（→Webサイト料金へ）」「コミュニティについて」
- イベント申込はLINEの返信 or Googleフォームで受付（初期は運営コスト最小を優先）

## 5. リスクと対策

| リスク | 対策 |
|---|---|
| 無料イベントに人が来ない | 定員を小さく（10名）始めて「満席」実績を作る。知人・既存フォロワーに初回サクラ的参加を依頼 |
| 無料→有料の壁が越えられない | ビジターとしてDiscordに入れ、会員限定チャンネルの存在を見せる（FOMO設計）。都度課金2,000円との比較を常に提示 |
| 講師が主宰者一人に依存 | 3ヶ月目以降「メンバー登壇枠」を作り、教える側を育てる（登壇者は当月会費無料などの特典） |
| 会場費が先行して赤字 | 公共施設（市民活動センター等）の格安会議室を併用。柏・松戸は1時間数百円の公共スペースあり |
